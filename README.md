# 🧮 BMI Calculator

A responsive and interactive **BMI (Body Mass Index) Calculator** developed using **HTML, CSS, and JavaScript**.  
This project calculates BMI using user height and weight inputs and displays the corresponding health category instantly.

---

# 📌 Features

✅ Instant BMI calculation  
✅ Multiple unit support  
- Height: cm, m, ft  
- Weight: kg, lbs  

✅ Responsive and modern UI  
✅ BMI category detection  
✅ Input validation  
✅ Animated result section  
✅ Health-related feedback and descriptions

| 25 – 29.9 | Overweight |
